# 🛡️ Silent Shift: Detecting the Insider Before the Incident (P03)

An MVP solution for the Manipal Hackathon 2026. This project uses unsupervised machine learning (Isolation Forests) to establish behavioral baselines and detect gradual data exfiltration, while utilizing a Context-Awareness Engine to suppress false positives caused by legitimate HR/IT changes.

## 🚀 How to Run the Demo

1. Clone the repository:
   `git clone [your-repo-link]`
2. Install dependencies:
   `pip install -r requirements.txt`
3. Launch the SOC Dashboard:
   `streamlit run app.py`

## 🧠 Tech Stack
* **Engine:** Python, scikit-learn (Isolation Forest)
* **Data Processing:** Pandas, NumPy
* **Frontend UI:** Streamlit
